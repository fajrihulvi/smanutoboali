# S14 — Presensi guru (sederhana)

## Rencana

1. Tabel `teacher_attendances` (modul Attendance): public_id, academic_year_id, teacher_id, date, check_in_at, check_out_at, status (enum `TeacherAttendanceStatus`), note, source (MANDIRI/OPERATOR), check_in_meta (IP, koordinat), recorded_by; unik (guru, tanggal); soft delete.
2. Guru: kartu **Presensi Masuk / Pulang** di dashboard (sekali per hari masing-masing) + ringkasan bulan ini.
3. Validasi lokasi opsional lewat pengaturan (default nonaktif): **daftar IP/CIDR** sekolah atau **radius GPS** dari koordinat sekolah.
4. Operator `/operator/presensi-guru`: daftar semua guru aktif per tanggal (status, jam masuk/pulang), koreksi manual & input izin/sakit/dinas lewat dialog (tercatat audit), rekap periode.
5. Kepala sekolah `/kepala-sekolah/presensi-guru`: rekap kehadiran guru per periode.
6. Menu: "Presensi" operator & "Monitoring Presensi" kepala sekolah menjadi grup Siswa / Guru.

## Keputusan

- Status guru: HADIR, TERLAMBAT, IZIN, SAKIT, DINAS (tugas luar), ALPA. Presensi mandiri menghasilkan HADIR atau TERLAMBAT; status lain diinput/dikoreksi operator.
- **Terlambat** bila presensi masuk setelah jam batas di pengaturan (`teacher_late_after`, default 07:15).
- Presensi mandiri hanya untuk **hari ini** (bukan Minggu); pulang hanya setelah masuk, masing-masing sekali. Guru yang berstatus IZIN/SAKIT/DINAS hari itu tidak bisa presensi masuk.
- Validasi lokasi (`teacher_attendance_validation`): NONAKTIF / IP / GPS. IP mendukung alamat tunggal & CIDR (IPv4/IPv6) dan memakai IP klien setelah TrustProxies. GPS memakai koordinat dari browser + jarak Haversine ke titik sekolah; **koordinat dari browser bisa dipalsukan**, jadi GPS hanya pencegah ringan (dicatat di `check_in_meta` untuk audit).
- Hari tanpa catatan tampil "Belum ada catatan", tidak otomatis dianggap ALPA (sekolah punya libur yang belum dimodelkan). Persentase kehadiran guru = (HADIR + TERLAMBAT + DINAS) ÷ hari tercatat.
- Koreksi operator menimpa status/jam dan menandai `source = OPERATOR`; nilai lama & baru dicatat di audit log.
- Presensi mandiri guru **tidak** dicatat di audit log (rutin, dua kali sehari per guru; metadata IP/koordinat tetap tersimpan di `check_in_meta`); koreksi/input operator dicatat lengkap dengan nilai lama.

## Hasil

- Tabel `teacher_attendances`, enum `TeacherAttendanceStatus` & `TeacherAttendanceValidation`, action `CheckInTeacherAction` / `CheckOutTeacherAction` / `CorrectTeacherAttendanceAction`, service `TeacherLocationGuard` (IP/CIDR via `IpUtils`, GPS Haversine) dan `TeacherAttendanceRecap`.
- Dashboard guru: kartu **Presensi Saya** (masuk/pulang, status, ringkasan bulan ini; meminta lokasi browser bila mode GPS). `DashboardPlaceholder` kini punya slot widget.
- Operator `/operator/presensi-guru`: daftar semua guru aktif per tanggal + dialog koreksi/input (izin, sakit, dinas, alpa), rekap periode `/operator/presensi-guru/rekap`.
- Kepala sekolah `/kepala-sekolah/presensi-guru`: rekap periode.
- Pengaturan Sekolah: bagian **Presensi guru** (jam batas terlambat, validasi lokasi, daftar IP, titik & radius sekolah) dengan validasi IP/CIDR dan koordinat wajib untuk mode GPS.
- Menu "Presensi" (operator) dan "Monitoring Presensi" (kepala sekolah) menjadi grup Siswa/Guru.
- **Bug navigasi yang ditemukan & diperbaiki:** penanda menu aktif memakai `startsWith` tanpa batas segmen, sehingga `/operator/presensi-guru` ikut menyalakan menu `/operator/presensi`. Kini per segmen (`isSameOrChildPath`, + Vitest).
- Uji klik di browser: tombol Presensi Masuk → toast jam & status → tombol berganti menjadi Presensi Pulang.
- Seeder demo: presensi guru 15 hari sekolah terakhir (±11% terlambat, sesekali izin/sakit/dinas); hari ini kosong.
