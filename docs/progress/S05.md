# S05 — RBAC

## Rencana

1. Modul **Access**. Enum `Permission` (format `modul.aksi`) sebagai satu sumber kebenaran: label Bahasa Indonesia, grup modul (untuk matriks UI S06), dan role default sesuai matriks §4.2.
2. `RolesAndPermissionsSeeder` idempoten: membuat 5 role + semua permission, lalu memberi permission default.
3. Alias middleware spatie `permission`, `role`, `role_or_permission`; dipakai di route bersama `active.role`.
4. Frontend: hook `usePermission()` (`can`, `canAny`, `canAll`) dan komponen `<Can>`.
5. `navigation.ts` sudah disaring `filterNavigation()` (S03) berdasarkan `auth.permissions` role aktif; kini diuji.
6. Core: kontrak ownership siswa (`StudentOwnershipGate` + trait `ChecksStudentOwnership` untuk Policy). Implementasi penuh di S10 (deny-by-default untuk guru/orang tua sampai scope `Student::visibleTo` ada).
7. Test: permission per role sesuai matriks, route tanpa permission → 403, seeder idempoten, menu per role (Vitest).

## Keputusan

- **Permission tambahan** di luar matriks §4.2 (dibutuhkan sesi Fase 1/2):
  - `setting.manage` (operator) — halaman Pengaturan Sekolah (S07).
  - `audit_log.view` (operator, kepala sekolah) — audit log, versi read-only kepala sekolah (S07).
  - `grade.view` (operator) — simbol 👁 operator pada baris `grade.manage` diterjemahkan menjadi permission lihat, bukan `grade.manage`.
- Seeder **tidak mencabut** permission yang sudah diubah operator lewat UI (S06): role yang baru dibuat mendapat set default penuh; permission yang baru dibuat diberikan ke role default-nya. Aman dijalankan ulang di produksi.
- Menu per role diuji dengan **Vitest** (dev dependency baru, `npm run test`), karena logika filter menu ada di TypeScript.
- Test Feature otomatis menjalankan `RolesAndPermissionsSeeder` (`$seed = true` di TestCase).

## Hasil

- Seeder di MariaDB: principal 7, teacher 10, operator 18, guardian 4, applicant 0 permission; dijalankan ulang tanpa perubahan.
- Pemakaian nyata middleware `permission:*` ada di route S06 (`/operator/users`, `/operator/roles`); di S05 diuji lewat route test.
- 78 test Pest + 7 test Vitest lulus; pint, phpstan, eslint, prettier, tsc, build hijau.
