# S07b — Checkpoint: persiapan deploy staging

## Rencana

1. `scripts/build-release.sh`: salinan bersih dari `git archive`, `composer install --no-dev --optimize-autoloader`, `npm ci && npm run build`, lalu arsip zip tanpa `node_modules`, `.env`, `tests`, `docs`, `storage/logs/*`.
2. `docs/DEPLOY_CPANEL.md`: struktur folder, document root, `.env` produksi, perintah artisan pertama kali, cron, permission folder, troubleshooting (500, mixed content, symlink).
3. `GET /health` (JSON): status app, database, queue (job gagal/antre + waktu terakhir diproses), scheduler (detak terakhir), versi. Dilindungi token `HEALTH_TOKEN` (header `X-Health-Token` atau `?token=`); tanpa token terkonfigurasi → 404.
4. Halaman error 403/404/419/500/503 bergaya Skoolia; `APP_DEBUG=false` tidak membocorkan detail error. Request Inertia yang kena 419 diarahkan kembali dengan pesan "Sesi berakhir".
5. Perintah `php artisan skoolia:make-operator` untuk membuat akun operator pertama di server (staging/produksi tanpa akun demo).
6. Dukungan HTTPS di balik proxy: `TRUSTED_PROXIES` dan `APP_FORCE_HTTPS`.

## Keputusan

- Halaman error memakai **Blade + CSS inline** (bukan Inertia/Vite) agar tetap tampil walau `public/build` belum terunggah atau aplikasi gagal boot. Ini satu-satunya tempat warna hex ditulis di luar `app.css`, dengan nilai token yang sama.
- Waktu terakhir queue diproses dan detak scheduler disimpan di cache (driver database) oleh listener `JobProcessed` dan tugas scheduler tiap menit.
- Versi aplikasi dari `APP_VERSION` di `.env`; skrip rilis menulis versi dari `git describe`.
- `skoolia:make-operator` ditambahkan (tidak diminta eksplisit) karena staging tanpa akun demo butuh cara aman membuat operator pertama; ini juga dasar seeder produksi di S35.

## Hasil

- Arsip rilis (`scripts/build-release.sh`, ±16 MB) diuji dengan simulasi server lokal: unzip → `.env` produksi (`APP_DEBUG=false`) → `key:generate`, `migrate --force`, seeder role, `skoolia:make-operator`, `optimize` → `/login` 200, 404 bergaya Skoolia, `/health` 403 tanpa token & 200 `status: ok` dengan token, login operator berhasil, portal lain 403.
- Temuan dari simulasi: `APP_VERSION` di `.env.example` menutupi file `VERSION` — diperbaiki (kosong → baca `VERSION`).
- Seeder demo dilewati otomatis saat `APP_ENV=production`.
- 157 test Pest + 7 Vitest lulus; pint, phpstan, eslint, prettier, tsc, build hijau.
