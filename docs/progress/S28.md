# S28 — CMS: backend

## Rencana

1. Modul baru **Cms** (panel operator `/operator/cms`, permission `cms.manage`):
   - `website_pages`: halaman statis Profil, Visi Misi, Sambutan, Struktur Organisasi, Fasilitas, Kontak (disiapkan otomatis) + halaman custom;
   - `website_categories` + `website_posts`: Berita & Agenda, dengan kategori, gambar utama, SEO title/description, dan waktu/lokasi untuk agenda;
   - `website_galleries` + `website_gallery_photos`: album berisi banyak foto + keterangan;
   - `website_banners`: gambar, judul, tautan, urutan, periode tayang;
   - `website_settings`: identitas situs, kontak, media sosial, peta, teks CTA PPDB, footer.
2. Editor rich text **TipTap** (judul, tebal/miring, daftar, kutipan, tautan, gambar) dengan unggah gambar ke disk publik lewat FileService. HTML **disanitasi di server** (symfony/html-sanitizer, whitelist tag & atribut) sebelum disimpan.
3. Status konten DRAFT → REVIEW → PUBLISHED → ARCHIVED (`canTransitionTo`), jadwal terbit (`publish_at`), dan **pratinjau** sebelum terbit.
4. Guru di website: kolom baru `teachers.show_on_website` & `website_title`; halaman CMS untuk memilih guru yang tampil (data tetap dari modul People).
5. Test: akses (hanya `cms.manage`), sanitasi XSS, transisi status, jadwal terbit, slug unik, halaman sistem tidak bisa dihapus.

## Keputusan

- **Penerbitan oleh pengelola CMS** (jawaban pengguna): semua pemegang `cms.manage` bisa mengajukan REVIEW dan menerbitkan. REVIEW menjadi penanda "siap diperiksa" + pratinjau, tanpa role tambahan.
- **Galeri berupa album** (jawaban pengguna) dengan banyak foto, masing-masing dengan keterangan dan urutan.
- Status "terjadwal" tidak disimpan sebagai status terpisah: konten PUBLISHED dengan `publish_at` di masa depan baru tampil publik saat waktunya tiba (dicek saat query, tanpa cron).
- Halaman sistem (Profil, Visi Misi, dst.) dibuat otomatis oleh migrasi, bisa diubah dan diarsipkan tetapi tidak dihapus. Slug-nya tetap agar menu website stabil.
- Slug dibuat otomatis dari judul (unik; bila bentrok diberi akhiran angka) dan bisa diubah manual. Slug halaman sistem terkunci.
- Gambar editor, gambar utama, banner, dan foto galeri disimpan **publik** (folder `website`) lewat FileService (dikompres ≤ 1600 px). URL-nya memakai `FileUrlGenerator`, sehingga tetap jalan tanpa `storage:link`.
- Pratinjau di S28 memakai tampilan Blade sederhana. Tampilan website sebenarnya dibuat di S29 (templatenya dipakai ulang untuk pratinjau).
- Isi HTML yang diizinkan: p, h2–h4, strong/b, em/i, u, s, a (http/https/mailto/tel, rel="noopener noreferrer" dipaksa), ul/ol/li, blockquote, br, hr, img (src http/https atau path relatif, alt, width, height), figure/figcaption. Script, style, iframe, event handler, dan `javascript:` dibuang.

## Hasil

- Modul **Cms** (`/operator/cms`, middleware `active.role:operator` + `permission:cms.manage`, `WebsiteContentPolicy`):
  - Halaman (6 halaman sistem dari migrasi + custom), Berita & Agenda (satu controller, segmen URL `berita`/`agenda`; berita tidak bisa dibuka lewat URL agenda), Kategori, Galeri (album), Banner, Guru di Website, Pengaturan website.
  - Menu "CMS Website" operator kini bersub-menu.
- Layanan:
  - `ContentSanitizer` (symfony/html-sanitizer, whitelist sesuai keputusan; `div/span/h1/h5/h6` dilepas tetapi teksnya dipertahankan; `rel="noopener noreferrer"` dipaksa);
  - `SlugGenerator` (unik termasuk baris terhapus, akhiran -2, -3, …; slug halaman yang bentrok dengan URL aplikasi ditolak lewat `WebsitePage::RESERVED_SLUGS`);
  - `ContentPublisher` (validasi `canTransitionTo`, `publish_at` hanya untuk TERBIT, `published_at` = jadwal atau saat pertama terbit);
  - `WebsiteMedia` (gambar publik folder `website`, maks 5 MB, dikompres FileService);
  - `WebsiteSettings` (nilai default + cache, dibersihkan saat disimpan).
- Status "Terjadwal" ditampilkan di panel untuk konten TERBIT dengan jadwal di masa depan; tampil publik lewat scope `live()` tanpa cron.
- Aksi cepat di daftar: pratinjau & ubah status sesuai transisi yang diizinkan (terbitkan dari daftar = langsung tayang).
- Pratinjau Blade sederhana (`cms::preview`, `noindex`) untuk halaman, berita/agenda, dan album. Akan diganti template website di S29.
- Editor **TipTap** (`RichTextEditor`): judul bagian, tebal/miring/garis bawah/coret, daftar, kutipan, garis pemisah, tautan, sisip gambar (unggah ke `/operator/cms/gambar-editor`, dibatasi 30/menit). Gaya isi memakai varian Tailwind per komponen (`PROSE_CLASS`), tanpa CSS global.
- Galeri: tambah banyak foto, keterangan per foto, geser urutan, hapus foto (maks 60 per album).
- Guru di website: centang tampil + jabatan (disimpan saat keluar dari kolom). Data guru tetap dari modul People.
- Seeder `CmsDemoSeeder`: isi 6 halaman sistem, 3 kategori, 4 berita terbit + 1 siap ditinjau + 1 terjadwal, 2 agenda, 1 album 6 foto, 2 banner, pengaturan, 8 guru tampil (gambar demo dibuat dengan GD).
- 547 test Pest (23 baru di S28) + 27 Vitest lulus; pint, phpstan, eslint, prettier, tsc, dan build hijau. Screenshot 1440/360 tanpa overflow untuk 12 halaman CMS.
