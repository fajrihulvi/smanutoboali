# S12 — Akademik: jadwal & materi

## Rencana

1. Tabel `schedules` (modul Academic): public_id, academic_year_id, teaching_assignment_id, day_of_week (1 = Senin … 6 = Sabtu), start_time, end_time, room; soft delete.
   Validasi di Action: jam selesai > jam mulai, **bentrok guru** (guru yang sama, hari sama, jam beririsan di tahun ajaran sama) dan **bentrok rombel**.
2. Tabel `learning_materials`: public_id, academic_year_id, teaching_assignment_id, title, description, type (FILE/LINK), url, created_by; file lewat FileService (`fileable`, direktori `materials`, privat); soft delete.
3. Operator `/operator/akademik/jadwal`: pilih tahun ajaran + rombel → grid mingguan (kolom Senin–Sabtu, kartu jadwal urut jam); tambah/ubah/hapus lewat dialog, mapel dipilih dari penugasan rombel tersebut.
4. Guru `/guru/akademik/jadwal`: jadwal hari ini + mingguan (hanya jadwal miliknya, tahun ajaran aktif).
   Guru `/guru/akademik/materi`: daftar materi miliknya, filter per mapel-rombel, tambah (file atau tautan + deskripsi), ubah, hapus.
5. Orang tua `/orang-tua/akademik`: jadwal mingguan & daftar mapel anak (guru pengampu + materi), dengan **StudentSwitcher** bila anak > 1.
6. Kepala sekolah `/kepala-sekolah/akademik`: ringkasan per rombel (jumlah jam per minggu, mapel belum terjadwal) + grid jadwal rombel terpilih (read-only).
7. Penjaga: penugasan yang masih punya jadwal/materi tidak bisa dikosongkan; mengganti guru pengampu ditolak bila guru baru bentrok dengan jadwalnya.
8. Test akses per role & ownership (guru hanya materi miliknya, orang tua hanya anaknya, file materi hanya untuk yang berhak).

## Keputusan

- Hari sekolah **Senin–Sabtu** (1–6); kolom Sabtu di tampilan baca hanya muncul bila ada jadwal hari Sabtu.
- Jadwal memakai **jam bebas** (HH:MM), bukan tabel jam pelajaran tetap — lebih fleksibel untuk sekolah yang jam pelajarannya berbeda per hari; bentrok dicek dengan irisan interval.
- Jadwal milik penugasan (`teaching_assignment`), jadi saat guru pengampu diganti, jadwal ikut guru baru (dengan cek bentrok).
- Jadwal memakai soft delete karena `attendance_sessions.schedule_id` (S13) akan merujuknya.
- Materi terikat ke **mapel di rombel** (penugasan), satu materi = satu file **atau** satu tautan; tanpa status draf. Orang tua ikut melihat materi mapel anaknya (read-only).
- Tautan materi wajib `http(s)://`.
- StudentSwitcher memakai query `?anak=<public_id>`; default anak pertama (urut nama). Resolver dibuat di modul People agar dipakai ulang oleh presensi, nilai, raport, portofolio.
- Kepala sekolah hanya membaca; operator tidak mengelola materi (domain guru).
- File materi yang diizinkan: PDF, dokumen Office (Word/PowerPoint/Excel, OOXML & format lama), dan gambar. ZIP generik ditolak karena MIME diperiksa dari isi file.
- Di layar kecil, grid jadwal berubah menjadi **tab hari** (default hari ini) — tanpa ini halaman akademik orang tua di 360px setinggi ±3.800px.

## Hasil

- Modul Academic: `schedules`, `learning_materials`, enum `Weekday` & `MaterialType`, `ScheduleConflictChecker`, `Timetable`, policy jadwal & materi (dipakai juga FilePolicy untuk unduh file materi).
- Operator: `/operator/akademik/jadwal` (grid mingguan per rombel, tambah per hari, klik kartu untuk ubah/hapus). Menu "Akademik › Jadwal Pelajaran".
- Guru: `/guru/akademik/jadwal` (hari ini + mingguan), `/guru/akademik/materi` (file/tautan, filter mapel, cari, ubah, hapus).
- Orang tua: `/orang-tua/akademik` dengan **StudentSwitcher** (komponen bersama + `GuardianChildren` di People), jadwal & mapel anak beserta materinya.
- Kepala sekolah: `/kepala-sekolah/akademik` — jam per minggu per rombel, mapel belum terjadwal, grid rombel terpilih.
- Penjaga baru di matriks penugasan: mapel yang sudah punya jadwal/materi tidak bisa dikosongkan; guru pengganti dicek bentrok jadwal. Penolakan tampil sebagai toast.
- Tambahan kecil: komponen `Textarea` (shadcn) menggantikan 3 textarea mentah, `ListSkeleton`, helper `Teacher::activeForUser()`, helper durasi jadwal (+ Vitest).
- Seeder demo: 110 slot jadwal tanpa bentrok (tiap mapel 2 JP/minggu), 2 materi tautan Matematika milik `guru@`.
- 341 test Pest + 9 Vitest lulus; pint, phpstan, eslint, prettier, tsc, build hijau. Screenshot 1440/360 tanpa overflow horizontal.
