# S13 — Presensi siswa

## Rencana

1. Modul baru **Attendance** (`php artisan make:module Attendance`):
   - `attendance_sessions`: public_id, academic_year_id, semester_id, classroom_id, date, schedule_id (nullable, mode per mapel), recorded_by, updated_by; soft delete.
   - `attendance_records`: attendance_session_id, student_id, status (enum `AttendanceStatus` HADIR/SAKIT/IZIN/ALPA/TERLAMBAT), note; unik (sesi, siswa).
2. Pengaturan baru di halaman Pengaturan Sekolah: **mode presensi** (harian / per mapel) dan **batas edit** (hari).
3. Guru `/guru/presensi`: pilih tanggal → daftar rombel (mode harian) atau slot jadwal (mode per mapel) beserta status sudah/belum diisi → halaman isi presensi dengan tombol status cepat, default HADIR, "Tandai semua hadir", catatan per siswa.
4. Event `AttendanceRecorded` → listener antre `NotifyGuardiansOfAbsence` → notifikasi database + email ke orang tua bila anak **baru** berstatus ALPA/TERLAMBAT.
5. Rekap: bulanan per rombel (matriks siswa × tanggal + jumlah per status + persentase), kalender kehadiran per siswa. Dipakai guru (rombelnya), operator (semua), kepala sekolah (semua).
6. Orang tua `/orang-tua/presensi`: kehadiran hari ini + kalender bulanan + ringkasan (StudentSwitcher).
7. Kepala sekolah `/kepala-sekolah/presensi`: statistik periode per rombel → drill-down siswa → kalender siswa.
8. Operator `/operator/presensi`: status pengisian semua rombel per tanggal, koreksi presensi kapan pun (tercatat audit), rekap.
9. Test: guru tidak bisa presensi rombel yang tidak diajarnya; orang tua hanya melihat anaknya; batas edit; notifikasi hanya saat status berubah.

## Keputusan

- **Siapa boleh mengisi:** mode harian — wali kelas atau guru yang mengajar di rombel itu; mode per mapel — hanya guru pengampu jadwal tersebut, dan hanya pada hari sesuai jadwal. Operator boleh mengisi/mengoreksi semua.
- **Tanggal:** tidak boleh di masa depan, bukan hari Minggu, dan harus berada di dalam salah satu semester tahun ajaran aktif. Semester sesi diambil dari rentang tanggal semester.
- **Batas edit** (`attendance_edit_days`, default 0): guru bisa **mengisi maupun mengubah** presensi sampai N hari setelah tanggalnya (0 = hanya hari yang sama) — mencegah pengisian mundur. Lewat dari itu hanya operator.
- **Mode presensi** (`attendance_mode`, default HARIAN). Sesi lama tetap sah bila mode diganti; rekap membaca keduanya.
- Satu sesi harian per rombel per tanggal; satu sesi per jadwal per tanggal (dijaga Action dengan lock, karena MySQL membolehkan NULL ganda di indeks unik).
- Siswa yang dicatat = anggota aktif rombel. Semua siswa di daftar wajib punya status (default HADIR di UI).
- **Persentase kehadiran** = hari HADIR/TERLAMBAT ÷ hari tercatat (dihitung dari status harian, sehingga mode harian dan per mapel sebanding).
- **Status harian** saat ada beberapa sesi per hari (mode per mapel): prioritas ALPA > SAKIT > IZIN > TERLAMBAT > HADIR.
- Notifikasi dikirim hanya saat status siswa **berubah menjadi** ALPA/TERLAMBAT (menyimpan ulang status yang sama tidak mengirim ulang), lewat antrean (driver `database`).
- Penolakan karena batas edit dikembalikan sebagai error validasi (field `date`), bukan 403, agar guru melihat pesan yang jelas.

## Hasil

- Modul **Attendance**: `attendance_sessions`, `attendance_records`, enum `AttendanceStatus` & `AttendanceMode`; service `AttendanceAccess`, `AttendanceTarget`, `AttendanceRoster`, `AttendanceRecap` (status harian diringkas lewat SQL), `AttendancePages`, `AttendanceSettings`.
- `RecordAttendanceAction` (lock rombel, audit `attendance`), event `AttendanceRecorded` → listener antre `NotifyGuardiansOfAbsence` → `StudentAbsenceNotification` (database + email).
- Guru & operator (`/guru/presensi`, `/operator/presensi`): daftar per tanggal (harian/per mapel) dengan status sudah/belum diisi, halaman isi (status cepat, tandai semua hadir, catatan, bilah simpan sticky, kunci setelah batas edit), rekap bulanan rombel, kalender siswa. Keduanya memakai satu controller dasar.
- Orang tua `/orang-tua/presensi`: hari ini, kalender bulanan, ringkasan, daftar hari tidak hadir penuh (StudentSwitcher).
- Kepala sekolah `/kepala-sekolah/presensi`: statistik periode per rombel → per siswa → kalender; rekap bulanan.
- Pengaturan Sekolah: bagian **Presensi** (mode & batas edit).
- **Bug tata letak yang ditemukan:** `sr-only` di header tabel lolos dari wrapper `overflow-x-auto` (absolute tanpa induk ber-position) dan membuat halaman melebar di 360px — wrapper tabel gulir kini `relative`.
- Uji ujung-ke-ujung di browser: isi ALPA → simpan → job antre diproses `queue:work --stop-when-empty` → notifikasi orang tua masuk.
- Seeder demo: presensi harian 15 hari sekolah terakhir (hari ini sengaja kosong); Aisyah punya 1 SAKIT + 1 ALPA.
