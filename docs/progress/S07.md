# S07 — Core services: file, audit, settings, notifikasi dasar

## Rencana

1. **Files**: tabel `files` (public_id, disk, visibility, directory, original_name, stored_name, path, mime_type, size, width/height, fileable morph, uploaded_by, soft delete). `FileService::store()` memvalidasi MIME asli (finfo, bukan ekstensi), ukuran maksimum dari Settings, nama acak ULID, kompres gambar > 1600px (intervention/image, driver GD). Disk `private` (storage/app/private) & `public`.
2. `GET /files/{file}` (auth) men-stream file setelah `FilePolicy::view` (publik → boleh; pengunggah → boleh; selain itu didelegasikan ke policy `view` milik model `fileable`). `GET /media/{file}` untuk file publik bila `storage:link` tidak tersedia; `FileUrlGenerator` memilih symlink atau route fallback.
3. **Audit log**: semua activity otomatis menyimpan `ip` & `user_agent` di properties; log `auth` untuk login/logout/switch role/reset password. Halaman `/operator/audit-log` dan `/kepala-sekolah/audit-log` (read-only) dengan filter modul, user, rentang tanggal.
4. **Settings**: tabel `settings` (key, value JSON) + `SettingsService` ber-cache; enum `SettingKey` dengan default. Halaman `/operator/settings`: nama sekolah, logo (FileService), alamat, telepon, email, zona waktu, ukuran maksimum upload. Nama & logo sekolah dibagikan ke Inertia.
5. **Notifikasi**: tabel `notifications` Laravel; `GET /notifikasi/terbaru` (JSON untuk dropdown lonceng), `POST /notifikasi/{id}/dibaca`, `POST /notifikasi/dibaca-semua`; badge unread di topbar dari shared props.
6. **Scheduler**: `queue:work --stop-when-empty --max-time=50` tiap menit (`withoutOverlapping`), `model:prune` & `activitylog:clean` harian.
7. Test: MIME palsu ditolak, ukuran berlebih ditolak, gambar besar dikompres, file privat oleh user tak berhak → 403, fallback publik, audit log akses & filter, settings + cache, notifikasi, scheduler terdaftar.

## Keputusan

- Kolom tambahan `files.directory` (kategori folder §15: students, teachers, portfolios, …, settings) dan `width`/`height` untuk gambar. Tidak ada kolom lain di luar §15 + permintaan S07.
- Zona waktu dari Settings diterapkan saat boot (`config('app.timezone')`), dengan catatan di UI bahwa sebaiknya hanya diubah saat awal instalasi karena memengaruhi penyimpanan waktu.
- Batas ukuran upload dari Settings dibatasi maksimum 20 MB (`config('skoolia.upload.hard_max_kb')`) agar tidak melampaui batas PHP hosting.
- `UserPolicy::view` ditambahkan (diri sendiri atau `user.manage`) sebagai contoh dan uji delegasi FilePolicy ke policy pemilik file.
- Seeder demo mengirim satu notifikasi "Selamat datang" ke setiap akun demo agar lonceng bisa dicoba.

## Hasil

- **Temuan saat implementasi:** `UploadedFile::getMimeType()` pada file palsu Laravel menebak dari nama file, sehingga test "MIME palsu" awalnya lolos. `FileService` kini selalu mendeteksi MIME dengan `finfo` langsung pada isi file, dan ekstensi file diturunkan dari MIME hasil deteksi.
- Audit log mencatat `ip` & `user_agent` otomatis; log `auth` (login, logout, switch role, reset password), `access` (S06), `settings`.
- Nama sekolah dari Pengaturan tampil di sidebar & halaman login; logo tersedia di shared props `school.logo_url`.
- Halaman `/operator/settings`, `/operator/audit-log`, dan dropdown lonceng dicek lewat login sungguhan (puppeteer) di 1440px & 360px.
- 143 test Pest + 7 Vitest lulus; pint, phpstan, eslint, prettier, tsc, build hijau.
