# S29 — Website publik (Blade)

## Rencana

1. Website profil sekolah dengan **Blade + Tailwind** (tanpa Inertia/React) di `resources/views/public`, CSS terpisah `resources/css/public.css` (entri Vite sendiri, token warna sama dengan aplikasi).
2. Halaman:
   - Beranda: banner, sambutan, berita terbaru, agenda mendatang, galeri, ajakan PPDB;
   - Profil, Visi Misi, Sambutan, Struktur Organisasi, Fasilitas, halaman custom (`/{slug}`), Kontak (isi + alamat, telepon, WhatsApp, email, peta);
   - Berita (daftar + filter kategori + detail), Agenda (mendatang & lampau + detail), Galeri (album + detail), Guru;
   - PPDB: info periode aktif, jalur & kuota, persyaratan dokumen, tombol Daftar / Masuk / Cek hasil;
   - tautan **Masuk** ke `/login`.
3. Mobile-first, tanpa JS berat: menu ponsel memakai `<details>`, slider banner memakai CSS scroll-snap.
4. SEO: judul & deskripsi dinamis (SEO title/description atau ringkasan), canonical, Open Graph + Twitter card, JSON-LD organisasi, `sitemap.xml`, `robots.txt` dinamis (menyebut sitemap dan menutup portal).
5. Cache halaman: middleware menyimpan HTML untuk tamu (GET, tanpa query selain `page`/`kategori`), dibersihkan otomatis saat konten website, guru tampil, atau periode PPDB berubah.
6. Pratinjau CMS memakai template website yang sama (dengan bilah "Pratinjau" dan `noindex`).
7. Test: halaman publik tampil, konten draf/arsip/terjadwal tidak tampil (404), rute slug tidak menimpa rute aplikasi, sitemap & robots, cache HIT/MISS & dibersihkan saat terbit, meta SEO, halaman guru & PPDB.

## Keputusan

- Halaman `/{slug}` didaftarkan **paling akhir** (setelah semua provider modul boot) dan dibatasi pola slug, sehingga tidak menimpa `/login`, `/ppdb/...`, dan rute portal. Slug yang bentrok sudah ditolak di CMS (S28).
- Rute `/` menjadi beranda website (nama rute `home` tetap). Halaman `Core::Welcome` dihapus.
- Cache: TTL 10 menit sebagai batas atas. Konten terjadwal tayang paling lambat 10 menit setelah jadwalnya tanpa cron. Kunci cache menyertakan versi yang dinaikkan setiap ada perubahan konten, sehingga pembersihan tidak butuh tag cache (aman untuk driver `file`/`database` di shared hosting).
- Nama & logo sekolah dari profil sekolah (modul School); kontak & media sosial dari Pengaturan Website (S28).
- `public/robots.txt` statis dihapus agar `robots.txt` dinamis bisa dilayani Laravel.

## Hasil

- Website publik Blade di `resources/views/public` (layout, header dengan menu Profil + menu ponsel `<details>`, footer kontak/tautan/media sosial) dengan CSS terpisah `public.css` (±40 kB, hanya memindai view publik). Token warna & font dipindah ke `resources/css/brand.css` dan dipakai aplikasi maupun website.
- Halaman:
  - Beranda: banner geser (scroll-snap + skrip kecil untuk tombol & putar otomatis, menghormati *reduced motion*), sambutan, 4 berita terbaru, 3 agenda mendatang, 3 album, ajakan PPDB sesuai periode;
  - `/{slug}` untuk halaman sistem & custom; Kontak menampilkan data kontak, WhatsApp, dan peta Google Maps;
  - `/berita` (filter kategori, paginasi) + detail dengan berita terkait;
  - `/agenda` (mendatang + sudah berlangsung) + detail dengan waktu & lokasi;
  - `/galeri` + detail album, `/guru`, `/ppdb` (periode aktif/mendatang, jalur, kuota, dokumen, langkah daftar, cek hasil).
- Tautan **Masuk** di header & footer menuju `/login`. Rute `/` kini beranda website (`Core::Welcome` dihapus). Dua test lama yang memakai `/` sebagai halaman Inertia dipindah ke `/login`.
- SEO:
  - `<title>`, meta description (SEO → ringkasan → isi), canonical, Open Graph (article untuk berita), Twitter card, JSON-LD `School`;
  - `sitemap.xml` (hanya konten tayang) dan `robots.txt` dinamis (menutup portal, menyebut sitemap); `public/robots.txt` statis dihapus.
- Cache halaman:
  - middleware `public.cache` (header `X-Page-Cache: HIT/MISS`), hanya untuk tamu, GET, dan query `page`/`kategori`, TTL 10 menit;
  - dibersihkan otomatis (versi cache dinaikkan) saat halaman/berita/galeri/foto/banner/kategori/pengaturan website, profil sekolah, periode/jalur/persyaratan PPDB, atau guru yang tampil berubah.
- Rute `/{slug}` didaftarkan setelah semua provider boot dan **tidak cocok dengan slug sistem** (`WebsitePage::RESERVED_SLUGS`), sehingga `/register` tetap 404 (juga untuk POST) dan rute aplikasi tidak tertimpa.
- Pratinjau CMS memakai template website yang sama (bilah "Pratinjau", `noindex`). View `cms::preview` sementara dari S28 dihapus.
- 17 test baru (`PublicWebsiteTest`): halaman tampil/404, konten draf/arsip/terjadwal, URL berita vs agenda, galeri, guru, PPDB, rute tidak tertimpa, meta SEO, sitemap, robots, pratinjau, cache HIT/MISS & pembersihan.
- 564 test Pest + 27 Vitest lulus; pint, phpstan, eslint, prettier, tsc, dan build hijau. Screenshot 1440/360 tanpa overflow untuk 10 halaman publik.
- Catatan: satu kali `ErrorException` muncul pada run paralel (`DeploymentReadinessTest`, halaman error), tidak terulang pada 3 run berikutnya dan lulus bila dijalankan sendiri. Polanya sama dengan catatan S27 (kemungkinan balapan kompilasi view Blade antar proses paralel). Tetap dipantau.
