# S21 — Chat: UI

## Rencana

1. Halaman chat per portal: `/kepala-sekolah/chat`, `/guru/chat`, `/operator/chat`, `/orang-tua/chat`, plus `/<portal>/chat/{percakapan}` untuk ruang chat (URL bisa dibagikan, tombol kembali di ponsel berfungsi). Satu page Inertia `Chat::Index`; orang tua memakai ParentLayout.
2. Desktop: dua panel (daftar percakapan | ruang chat). Ponsel: satu panel, dengan navigasi daftar → ruang → kembali.
3. Daftar percakapan: avatar inisial, nama + peran ("Bu Rina · Wali Kelas VII-A"), konteks anak, cuplikan pesan terakhir, waktu relatif, badge unread, ikon bisu, pencarian, tab Kotak masuk/Arsip.
4. Ruang chat:
   - bubble (pesan sendiri brand-600 teks putih, lawan bicara putih berborder), pemisah tanggal;
   - centang terkirim/dibaca, preview gambar (lightbox) dan kartu PDF;
   - infinite scroll ke atas (cursor) dengan posisi scroll tetap; auto-scroll saat pesan baru bila pengguna sedang di bawah;
   - optimistic update dengan status mengirim/gagal + tombol "Coba lagi";
   - ubah/hapus pesan sendiri; menu arsip/bisukan; banner hanya-baca.
5. Komposer: textarea auto-resize, Enter kirim, Shift+Enter baris baru, tombol lampiran (gambar/PDF ≤ 5 MB, dicek juga di klien).
6. Dialog "Percakapan baru" dari endpoint kontak, dikelompokkan per anak (orang tua) atau per rombel (guru); operator/kepsek mencari orang tua lewat pencarian.
7. Realtime via `useEchoChannel`:
   - `message.sent`/`message.updated`/`conversation.read` di ruang chat;
   - `chat.message` di channel user → toast (kecuali percakapan sedang dibuka atau dibisukan) dan badge unread di sidebar, bottom-nav, dan header orang tua, di-update realtime.
8. Fallback tanpa realtime: ruang chat dan daftar dimuat ulang berkala (15 detik) hanya saat koneksi realtime tidak aktif dan tab terlihat, juga saat tab kembali fokus.
9. Status online (presence) ditampilkan bila setting `chat_presence_enabled` aktif; toggle ada di Pengaturan Sekolah (operator).
10. Menu Chat untuk operator (sebelumnya belum ada) dan widget "Chat belum dibaca" di dashboard guru memakai data nyata.

## Keputusan

- Ruang chat memakai API JSON S20. Props Inertia hanya berisi daftar awal dan detail percakapan aktif, sehingga pindah percakapan tidak memuat ulang seluruh halaman (`only: ['active']`).
- Badge unread memakai shared prop `chat.unread` sebagai nilai awal lalu diperbarui lewat event DOM `skoolia:chat-unread`, tanpa store global (pola sama dengan lonceng notifikasi).
- Duplikasi pesan dari optimistic update vs broadcast dicegah dengan dedup berdasarkan `public_id`. Broadcast pesan milik sendiri diabaikan selama masih ada pesan "mengirim" di tab tersebut, karena respons POST yang akan menggantinya.
- Polling fallback 15 detik hanya aktif ketika Pusher tidak tersambung (hemat request di shared hosting).

## Hasil

- Halaman `Chat::Index` untuk keempat portal (`/<portal>/chat[/{percakapan}]`). Dua panel di desktop; di ponsel satu panel dengan tombol kembali. Orang tua memakai ParentLayout (mobile-first).
- Komponen `ConversationList`, `ChatRoom`, `MessageBubble`, `Composer`, `NewConversationDialog`, `ChatAvatar`; helper murni `Modules/Chat/lib.ts` (merge/dedup, tandai dibaca, pemisah tanggal, validasi lampiran) dengan 7 test Vitest.
- Realtime: `message.sent`/`message.updated`/`conversation.read` di ruang chat; `chat.message` di RealtimeBridge untuk toast "Pesan dari …" (tidak muncul bila percakapan sedang terbuka atau dibisukan) dan badge.
- Badge chat realtime (`useChatUnread`) di sidebar staf, bottom-nav, menu samping, dan header orang tua; widget "Chat belum dibaca" di dashboard guru memakai data nyata.
- Fallback: polling 15 detik hanya saat Pusher tidak tersambung, plus muat ulang saat tab kembali aktif.
- Menu Chat untuk operator; toggle "Tampilkan status online di chat" di Pengaturan Sekolah → presence `chat.online` (titik hijau).
- `sendJson` mendukung PATCH dan FormData.
- Helper test chat dipindah ke `tests/Pest.php` agar bisa dipakai lintas file saat test paralel.
- 466 test Pest + 27 Vitest lulus; pint, phpstan, eslint, prettier, tsc, dan build hijau. Screenshot guru & orang tua di 1440/360 tanpa overflow horizontal.
