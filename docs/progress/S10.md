# S10 — Siswa + relasi orang tua (N:M) + scope ownership

## Rencana

1. `students`: public_id, nis (wajib, unik), nisn (opsional, 10 digit, unik), name, gender, birth_place, birth_date, religion, address, photo_file_id, status (AKTIF/LULUS/PINDAH/KELUAR, enum dengan `canTransitionTo()`), entry_date, soft delete.
   `guardian_student`: guardian_id, student_id, relationship (AYAH/IBU/WALI), is_primary; unik per pasangan; satu orang tua utama per siswa (dijaga Action).
2. CRUD `/operator/master-data/siswa` dengan tab: Identitas, Orang Tua (tautkan orang tua yang ada / buat baru / lepas / jadikan utama), Riwayat Kelas (menyusul S11).
3. Import Excel siswa + orang tua: template unduh, upload → Job (`queue` database) membaca per chunk, validasi per baris, laporan baris gagal.
4. `Student::visibleTo(User $user, ?Role $as = null)` sesuai §4.3 (guru menyusul S11).
5. `StudentPolicy` memakai scope tersebut; `StudentOwnershipGate` di Core di-rebind ke implementasi People.
6. Orang tua: `/orang-tua/anak` & `/orang-tua/anak/{public_id}` (daftar & detail anak) sebagai titik uji ownership; kepala sekolah: `/kepala-sekolah/siswa` read-only.
7. Test ownership: orang tua A tidak bisa membuka siswa B (403), termasuk manipulasi public_id.

## Keputusan

- Tabel tambahan **`student_imports`** (status, jumlah baris sukses/gagal, daftar error per baris, file sumber, pembuat) untuk melacak import di Job — tidak ada di spesifikasi, diperlukan untuk "laporan baris gagal".
- Import: **NIS yang sudah terdaftar ditolak** per baris (tidak menimpa data). Orang tua dicocokkan ulang berdasarkan email, atau nama + telepon, agar kakak-adik berbagi data orang tua; orang tua utama = yang pertama terisi (ayah → ibu → wali).
- Agama memakai enum 6 agama resmi (ISLAM, KRISTEN, KATOLIK, HINDU, BUDDHA, KONGHUCU).
- Transisi status: AKTIF → LULUS/PINDAH/KELUAR; PINDAH/KELUAR → AKTIF (koreksi/kembali); LULUS final.
- `visibleTo()` tanpa parameter role memakai role aktif di sesi; kepala sekolah & operator melihat semua; orang tua lewat `guardian_student`; **guru sementara tidak melihat siswa** sampai `teaching_assignments` ada (S11) — test guru ditandai skip.
- Data orang tua yang masih tertaut ke siswa tidak bisa dihapus (lepaskan dulu).

## Hasil

- Modul People: `students`, `guardian_student`, `student_imports`; CRUD siswa bertab (Identitas, Orang Tua, Riwayat Kelas — placeholder S11), hubungkan/lepas/jadikan utama orang tua, pencarian orang tua untuk kakak-adik.
- Import Excel (.xlsx/.csv) lewat `ImportStudentsJob` (queue database, chunk 200), laporan baris gagal di halaman, status diperbarui otomatis (`usePoll`) selama diproses; template bisa diunduh.
- **Bug yang ditemukan & diperbaiki:** `CarbonImmutable::createFromFormat()` melempar exception (bukan `false`) untuk tanggal DD/MM/YYYY sehingga seluruh import gagal — kini memakai `DateTimeImmutable`. Record import juga ikut dibatalkan bila file ditolak.
- `Student::visibleTo()` + `StudentPolicy` + `StudentVisibilityGate` (menggantikan deny-by-default S05). `/orang-tua/anak`, `/orang-tua/anak/{id}`, `/kepala-sekolah/siswa`.
- Test ownership: orang tua A → siswa B = 403 (manipulasi public_id), id numerik 404, foto siswa hanya orang tuanya/operator/kepala sekolah. Test guru di-skip sampai S11.
- Seeder demo: 30 siswa; `ortu@` punya 2 anak (kakak-adik berbagi ayah & ibu), `guru.ortu@` 1 anak.
- 246 test Pest (1 skip terencana) + 7 Vitest lulus; pint, phpstan, eslint, prettier, tsc, build hijau.
