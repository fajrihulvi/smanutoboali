# S34 — Backup, logging, observability

## Rencana

1. **Backup** (spatie/laravel-backup):
   - database harian (02.00), database + file upload mingguan (Minggu 03.00);
   - retensi: harian 7 hari, mingguan 4 minggu, bulanan 3 bulan;
   - `backup:clean` & `backup:monitor` terjadwal; email ke pengelola bila backup gagal atau tidak sehat;
   - tujuan default disk lokal privat `backups` (`storage/app/backups`); tujuan tambahan (S3/Google Drive) cukup lewat `.env` + paket adapter;
   - arsip ZIP bisa dienkripsi dengan password (`BACKUP_ARCHIVE_PASSWORD`);
   - uji restore di lokal.
2. **Logging:**
   - channel `daily` dengan retensi 14 hari;
   - log khusus `payment` (pembayaran online, webhook, verifikasi) dan `auth` (login berhasil/gagal, lockout, logout, reset password);
   - tanpa password/token/kunci di log.
3. **Halaman `/operator/sistem`** (permission `setting.manage`):
   - versi aplikasi, PHP, Laravel, database, driver cache/queue/sesi;
   - detak scheduler & antrean;
   - antrean: jumlah job menunggu, **job gagal + tombol coba lagi/hapus**;
   - backup terakhir (+ tombol "Backup database sekarang" lewat antrean);
   - ukuran storage per folder & sisa disk.
4. **Mode maintenance** bergaya Skoolia: halaman 503 sudah ada (S03). Diperbaiki agar aman dengan CSP; perintah `down`/`up` + secret bypass didokumentasikan.
5. Test: akses halaman sistem, retry/hapus job gagal, backup terjadwal & konfigurasi retensi, log payment/auth tertulis tanpa data rahasia, halaman 503.

## Keputusan

- **Log `payment` & `auth` disimpan 30 hari** (bisa diubah lewat `.env`), lebih lama dari log umum (14 hari), untuk menelusuri sengketa pembayaran atau akses mencurigakan.
- **"Backup sekarang" dari halaman sistem hanya untuk database, dan dijalankan lewat antrean** (bukan di request web) agar tidak kena batas waktu PHP di shared hosting.
- **Halaman sistem memakai permission `setting.manage`** yang sudah dimiliki operator, tanpa permission baru.
- **Log hanya ditampilkan daftar file & ukurannya**, bukan isinya, agar tidak ada data sensitif yang terbuka lewat web.

## Hasil

- **Backup** (`config/backup.php`, disk privat `backups`):
  - perintah `php artisan skoolia:backup database|files|clean` menjalankan job spatie langsung dengan nama `skoolia-database` / `skoolia-files`;
  - perintah bawaan `backup:run` menerima Config saat boot sehingga nama tidak bisa diganti di runtime. Tanpa pemisahan ini, strategi mingguan akan memangkas backup file.
- **Jadwal:** DB 02.30 harian, file Minggu 03.00, `clean` 04.00, `backup:monitor` 05.00.
  - retensi 7 hari / 4 minggu / 3 bulan;
  - batas 5 GB (`BACKUP_MAX_MB`);
  - email hanya saat gagal/tidak sehat (`BACKUP_MAIL_TO`);
  - arsip bisa dienkripsi (`BACKUP_ARCHIVE_PASSWORD`);
  - tujuan tambahan lewat `BACKUP_DISKS`.
- **mysqldump:** `--single-transaction --no-tablespaces`, path binary lewat `DB_DUMP_BINARY_PATH`.
- **Uji restore lokal:** dump dari ZIP diimpor ke database baru → jumlah baris 10 tabel utama (users, students, teachers, invoices, payments, attendance_records, report_cards, files, website_posts, activity_log) **identik**; arsip file berisi `private/` & `public/` dengan path relatif.
- **Log:**
  - channel `payment` & `auth` (harian, 30 hari) di samping `daily` 14 hari;
  - payment: mulai bayar online, callback gateway (ditolak = WARNING), catat/verifikasi/tolak pembayaran, unggah bukti — tanpa token/signature/payload mentah;
  - auth: login (berhasil, gagal + alasan, akun nonaktif), logout, reset password, lockout — tanpa password.
- **Halaman `/operator/sistem`** (menu "Sistem", `setting.manage`):
  - versi & lingkungan, kesehatan scheduler/antrean, jumlah job menunggu/diproses/gagal;
  - daftar job gagal dengan **Ulang** / **Hapus** / **Ulang semua**;
  - status backup per jenis & disk (sehat/perlu dicek) + **Backup database sekarang** (lewat antrean, dibatasi 3×/10 menit);
  - ukuran storage (di-cache 10 menit, tombol hitung ulang) & sisa disk, daftar file log;
  - semua aksi tercatat di audit log modul "Sistem".
- **Maintenance:** halaman 503 bergaya Skoolia sudah ada.
- **Bug yang ditemukan & diperbaiki:**
  - tautan `javascript:` di halaman error (Kembali/Muat ulang/Coba lagi) ikut terblokir CSP sejak S32 → diganti tautan biasa, dengan test agar tidak muncul lagi;
  - nilai kosong `BACKUP_MAIL_TO=` / `BACKUP_ARCHIVE_PASSWORD=` di `.env` terbaca sebagai string kosong → dianggap tidak diisi.
- `.env.example` diperbarui (log, keamanan, laporan, backup).
- 9 test baru (`tests/Feature/Core/SystemTest.php`). 647 test Pest + 31 Vitest lulus; pint, phpstan, eslint, prettier, tsc, dan build hijau. Screenshot 1440/360 halaman sistem tanpa overflow.
