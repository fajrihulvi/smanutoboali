# S08 — Sekolah & periode akademik

## Rencana

1. Modul **School**.
   - `schools` (satu baris): name, npsn, level (SD/SMP/SMA/SMK), address, phone, email, logo (File), principal_name, principal_nip. Migrasi memindahkan identitas lama dari `settings` (S07) lalu menghapus key-nya.
   - `academic_years`: public_id, name `2026/2027` (unik), start_date, end_date, is_active.
   - `semesters`: public_id, academic_year_id, type GANJIL/GENAP (unik per tahun), start_date, end_date, is_active. Dua semester dibuat otomatis saat tahun ajaran dibuat.
2. Aturan satu periode aktif dijaga di Action (transaksi + lock): `ActivateAcademicYearAction`, `ActivateSemesterAction`. Invarian: semester aktif selalu milik tahun ajaran aktif.
3. `App\Support\ActivePeriod`: `academicYear()`, `semester()`, `academicYearId()`, di-cache & dibersihkan saat aktivasi; dibagikan ke Inertia (`activePeriod`) dan tampil sebagai badge di topbar.
4. CRUD `/operator/master-data/tahun-ajaran` (permission `master_data.manage`): daftar + semester, tambah/ubah, aktifkan tahun/semester, hapus (hanya yang tidak aktif).
5. Halaman Pengaturan Sekolah pindah ke modul School: identitas (termasuk NPSN, jenjang, kepala sekolah) + pengaturan sistem (zona waktu, batas upload tetap di `settings`).
6. Test: mengaktifkan tahun ajaran baru menonaktifkan yang lama; aktivasi semester; validasi; akses per role; migrasi settings → schools.

## Keputusan

- (Dikonfirmasi) Profil sekolah di tabel `schools`; `settings` hanya untuk konfigurasi sistem.
- (Dikonfirmasi) Jenjang bisa diatur; `SchoolLevel::gradeRange()` (SD 1–6, SMP 7–9, SMA/SMK 10–12) dipakai validasi tingkat rombel di S11. Default jenjang: SMP.
- `schools` tidak memakai `public_id` karena tidak pernah tampil di URL (profil tunggal).
- Tahun ajaran & semester **tidak** memakai soft delete; penghapusan hanya untuk periode tidak aktif (nanti juga dicek tidak punya data turunan).
- Mengaktifkan tahun ajaran otomatis mengaktifkan semester GANJIL-nya bila belum ada semester aktif di tahun itu; mengaktifkan semester ikut mengaktifkan tahun ajarannya.
- Nama tahun ajaran wajib format `YYYY/YYYY+1`; tanggal default semester: GANJIL = mulai s.d. 31 Des, GENAP = 1 Jan s.d. selesai (bisa diubah).

## Hasil

- Modul School: `schools`, `academic_years`, `semesters`; profil sekolah (termasuk NPSN, jenjang, kepala sekolah) dipindah dari `settings` beserta migrasi datanya. Halaman Pengaturan Sekolah kini `School::Operator/Settings`.
- `ActivePeriod` terisi (cache + flush saat aktivasi), dibagikan sebagai `activePeriod` dan tampil sebagai badge "TA 2026/2027 · Ganjil" di topbar; bila belum diatur, operator melihat tautan "Periode belum diatur".
- Seeder demo: 2025/2026 dan 2026/2027 (aktif, Ganjil); dilewati di produksi.
- `/operator/master-data/tahun-ajaran` dicek via login sungguhan di 1440px & 360px.
- 174 test Pest + 7 Vitest lulus; pint, phpstan, eslint, prettier, tsc, build hijau.
