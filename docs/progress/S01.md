# S01 — Scaffold project

## Rencana

1. Ambil Laravel React Starter Kit versi Laravel 12 (commit `8f79a71`, sebelum upgrade ke Laravel 13 yang butuh PHP 8.3).
2. Kunci `config.platform.php = 8.2.0` agar lock file cocok dengan hosting PHP 8.2/8.3.
3. Konfigurasi: APP_NAME Skoolia, `Asia/Jakarta`, locale `id`, faker `id_ID`, MySQL, driver database untuk queue/session/cache.
4. Paket: spatie/laravel-permission, spatie/laravel-activitylog, barryvdh/laravel-dompdf, maatwebsite/excel, intervention/image, spatie/laravel-backup.
   Dev: Pest 3, Larastan 3 (level 6), Pint, laravel-lang/common (terjemahan `lang/id`).
   npm: @tanstack/react-table, recharts, date-fns, sonner.
5. Script npm `types`, `.env.example` berkomentar per blok, README.
6. Matikan SSR Inertia (tidak ada Node di server).

## Hasil

- Selesai. 40 test bawaan lulus; pint, phpstan, tsc, build hijau.
- `TestCase::setUp()` memanggil `withoutVite()` agar test tidak butuh `public/build`.
- `npm run types` menjalankan `wayfinder:generate` dulu karena file route TS dihasilkan saat build.
