# S15 — Penilaian

## Rencana

1. Modul baru **Assessment**:
   - `grade_components`: public_id, teaching_assignment_id, semester_id, academic_year_id, type (TUGAS/UH/PTS/PAS/PRAKTIK), name, weight (%), position, published_at, published_by; soft delete.
   - `grades`: grade_component_id, student_id, score (0–100, 2 desimal), note, updated_by; unik (komponen, siswa).
   - `grade_description_templates`: teaching_assignment_id, predicate (A/B/C/D), template; unik (penugasan, predikat).
   - `grade_descriptions`: teaching_assignment_id, semester_id, student_id, description, updated_by; unik (penugasan, semester, siswa).
2. Guru `/guru/akademik/nilai`: daftar mapel-rombel yang diampu per semester → buku nilai bergaya spreadsheet (navigasi keyboard, simpan otomatis per sel dengan debounce, indikator tersimpan), kelola komponen & bobot, nilai akhir + predikat otomatis, deskripsi capaian per siswa dengan template per rentang nilai.
3. Import/export nilai Excel per mapel-rombel per semester.
4. Publikasi per komponen → event `GradePublished` → notifikasi orang tua (database + email, antrean).
5. Orang tua `/orang-tua/nilai`: nilai terbaru yang sudah dipublikasikan (StudentSwitcher).
6. Kepala sekolah `/kepala-sekolah/nilai`: rata-rata nilai akhir per rombel × mapel + distribusi predikat.
7. Operator (`grade.view`): lihat buku nilai read-only.
8. Pengaturan Sekolah: KKM & batas predikat.

## Keputusan

Dari jawaban pengguna:

- **Nilai akhir** baru dihitung bila semua komponen siswa terisi **dan** total bobot = 100%; selain itu tampil "—".
- **KKM & batas predikat** satu aturan sekolah di Pengaturan Sekolah (default KKM 75; A ≥ 90, B ≥ 80, C ≥ 70, D < 70).
- **Template deskripsi** per mapel-rombel guru (4 predikat), otomatis diisi dari template bawaan; deskripsi per siswa tetap bisa disunting.
- **Komponen yang dipublikasikan terkunci**: nilai, bobot, dan komponennya tidak bisa diubah/dihapus sampai guru membatalkan publikasi (orang tua tidak melihatnya selama tidak dipublikasikan).

Diambil sendiri:

- Nilai akhir = Σ(nilai × bobot) ÷ 100, **dibulatkan ke bilangan bulat** (half-up) seperti di raport.
- Beberapa komponen boleh berjenis sama (mis. "UH 1", "UH 2"); nama wajib unik per mapel-rombel-semester.
- Bobot total ≠ 100% tidak memblokir input nilai, tetapi ditandai jelas dan nilai akhir tidak dihitung.
- Setiap aksi **publikasi** mengirim notifikasi (termasuk publikasi ulang setelah koreksi), satu notifikasi per orang tua per anak.
- Import Excel diproses **sinkron** (satu rombel ≤ ±40 siswa × beberapa komponen, jauh di bawah batas proses berat); baris dicocokkan via NIS, nilai kosong dilewati, komponen terkunci ditolak.
- Simpan per sel memakai request JSON (bukan kunjungan Inertia) agar grid tidak dimuat ulang tiap ketikan.
- Hanya siswa aktif di rombel yang tampil di buku nilai.

## Hasil

- Modul **Assessment**: `grade_components`, `grades`, `grade_description_templates`, `grade_descriptions`; enum `ComponentType` & `Predicate`; service `Gradebook` (per mapel-rombel), `GradeRecap` (massal satu semester, beberapa query saja — dipakai raport S16), `GradeAccess`, `AssessmentSettings`, `SemesterPicker`.
- Guru `/guru/akademik/nilai`: kartu mapel-rombel per semester → buku nilai spreadsheet (simpan otomatis per sel via JSON, debounce 600 ms + flush saat blur, Enter/↑/↓/←/→, indikator tersimpan/gagal, validasi 0–100 dengan koma), kelola komponen & bobot, publikasi/batal publikasi (mengunci nilai), deskripsi per siswa + template per predikat, isi deskripsi kosong dari template, ekspor/impor Excel.
- Event `GradePublished` → listener antre → `GradePublishedNotification` (database + email) per orang tua per anak.
- Orang tua `/orang-tua/nilai`: hanya komponen terpublikasi; nilai akhir muncul bila semua komponen terpublikasi & lengkap.
- Kepala sekolah `/kepala-sekolah/nilai`: rata-rata, terhitung, di bawah KKM, distribusi predikat per mapel + buku nilai read-only. Operator `/operator/nilai` (grade.view): buku nilai read-only.
- Pengaturan Sekolah: bagian **Penilaian** (KKM & batas predikat, validasi A > B > C).
- Helper frontend: `sendJson` + `HttpError` (pesan validasi 422 diteruskan ke UI), `parseScore`/`formatScore` (+ Vitest).
- **Masalah yang ditemukan & diperbaiki:** nama indeks unik otomatis melebihi 64 karakter di MySQL (lolos di SQLite test) — diberi nama pendek; closure `setTimeout` membaca nilai sel lama — diganti ref; grid & deskripsi tidak ikut termuat ulang setelah impor/isi template — di-*key* dengan tanda tangan data server.
- Uji di browser: ketik nilai → tersimpan otomatis, nilai akhir & predikat langsung dihitung, Enter pindah baris, isian > 100 ditandai merah. (Input keyboard/mouse bawaan puppeteer tidak sampai ke halaman di lingkungan ini, jadi dipakai event DOM React.)
- Seeder demo: 4 komponen per mapel (Tugas 20, UH 30, PTS 20, PAS 30), Tugas & UH terpublikasi; MTK VII-A dua siswa tanpa PAS.
- 392 test Pest + 19 Vitest lulus; pint, phpstan, eslint, prettier, tsc, build hijau. Screenshot 1440/360 tanpa overflow horizontal.
