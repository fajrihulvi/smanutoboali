# S03 — Design system & layout dasar

## Rencana

1. Token `brand-50..950` + `brand-accent` (sky `#38BDF8`) di `@theme` `resources/css/app.css`; variabel shadcn dipetakan ke token (primary = brand-600, ring = brand-500, radius 0.75rem). Font Plus Jakarta Sans (Google Fonts).
2. Layouts di `resources/js/Layouts`:
   - `AuthLayout` — split-screen: panel gradient biru (judul portal + ikon) | form putih; di mobile panel jadi header ringkas.
   - `AppLayout` — sidebar gradient navy (collapsible, item aktif `white/10` + garis kiri brand-500), topbar putih: breadcrumb, pencarian, lonceng (slot badge), role switcher, menu avatar.
   - `ParentLayout` — mobile-first, header ringkas + bottom navigation (Beranda, Anak, Chat, Tagihan, Profil); di ≥ md menjadi navigasi atas.
3. `resources/js/config/navigation.ts` — menu 4 role sesuai §5 spesifikasi (label, href, icon, permission, children). Data dummy; filter permission di S05.
4. `Components/shared`: PageHeader, StatCard, StatusBadge, DataTable (TanStack + paginasi server Laravel), Pagination, EmptyState, ConfirmDialog, FilterBar, FileUploader, Skeletons, FlashToaster (sonner membaca flash Inertia).
5. Shared props dasar di `HandleInertiaRequests`: `auth.user`, `auth.roles`, `auth.activeRole`, `auth.permissions`, `flash`, `notifications.unread` (diisi nyata di S04/S07).
6. Halaman `Core::StyleGuide` di `/style-guide`, hanya terdaftar saat `APP_ENV=local`.

## Keputusan

- Token aksen bernama `brand-accent` (bukan `accent`) karena `accent` sudah dipakai shadcn untuk latar hover.
- **Mode gelap dihapus** (appearance toggle, `HandleAppearance`, halaman settings/appearance). Design system Elegant Blue hanya mendefinisikan tema terang; mempertahankan dark mode berarti menggandakan pekerjaan desain setiap sesi.
- `href` di navigation.ts berupa path URL (bukan nama route) karena sebagian besar route tujuan baru dibuat di sesi berikutnya; Wayfinder tidak bisa mengimpor route yang belum ada.
- Sidebar memakai komponen shadcn `ui/sidebar` (sudah punya collapse + mobile sheet), di-theme lewat variabel `--sidebar-*`.

## Hasil

- Halaman `/style-guide` (+ `/style-guide/orang-tua`, `/style-guide/login?portal=…`) diperiksa lewat screenshot headless Chrome di 1440px dan iframe 360px: tidak ada scroll horizontal; palet dijadikan 3 kolom di mobile.
- TanStack Table yang terpasang adalah **v9** (API `useTable` + `tableFeatures`), DataTable ditulis untuk v9 tanpa fitur klien (paginasi/filter di server).
- Pencarian global di topbar baru kerangka UI (disabled, "segera hadir").
- 49 test lulus; pint, phpstan, eslint, prettier, tsc, build hijau.
