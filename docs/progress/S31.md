# S31 — Laporan & export

## Rencana

1. Modul baru **Report** dengan **pusat laporan**:
   - `/kepala-sekolah/laporan` & `/operator/laporan` (menu "Laporan" operator yang tadinya mengarah ke `/operator/reports` diperbaiki);
   - `/guru/laporan` untuk guru (hanya kelas/mapel miliknya);
   - akses: permission `report.export` + role aktif; laporan keuangan juga butuh `finance.view`/`finance.manage`, PPDB butuh `ppdb.manage`/`ppdb.decide`.
2. Jenis laporan (setiap laporan: filter → pratinjau tabel di layar → unduh PDF/Excel):
   - **Presensi siswa**: rentang tanggal, rombel (opsional) → hadir/terlambat/sakit/izin/alpa/% per siswa;
   - **Presensi guru**: rentang tanggal → rekap per guru (kepala sekolah & operator);
   - **Nilai**: semester + rombel → matriks nilai akhir per mapel (guru: mapel yang diajar, atau semua mapel bila wali kelasnya);
   - **Raport**: semester, rombel & status (opsional) → status raport per siswa;
   - **Penerimaan keuangan**: rentang tanggal, rombel → pembayaran terkonfirmasi + total;
   - **Tunggakan**: rombel (opsional) → tunggakan per siswa;
   - **PPDB**: periode, jalur & status (opsional) → daftar pendaftar.
3. Export:
   - **PDF** (dompdf, kop sekolah + logo, judul, keterangan filter, tanggal cetak, nomor halaman);
   - **Excel** (maatwebsite, angka tetap angka, judul sheet).
4. Export besar lewat **Job**:
   - catatan `report_exports` (pemilik, jenis, format, filter, status, jumlah baris, kedaluwarsa);
   - Job membuat file privat, lalu notifikasi in-app + email berisi tautan unduh;
   - tautan hanya untuk pemilik dan **kedaluwarsa 24 jam**; file dihapus oleh `model:prune`.
5. Riwayat ekspor pengguna (24 jam terakhir) di pusat laporan.
6. Test:
   - akses per role/permission, isi tiap laporan, scope guru (kelas lain ditolak);
   - ekspor langsung vs antrean, notifikasi, unduhan hanya pemilik, kedaluwarsa.

## Keputusan

- **Langsung atau antrean:**
  - laporan ≤ 300 baris diunduh langsung;
  - di atas itu dibuat oleh Job (antrean database yang diproses scheduler tiap menit) dan pengguna diberi tahu saat siap.
- **Satu tabel `report_exports` untuk semua jenis laporan** (filter disimpan sebagai JSON). File memakai tabel `files` yang sudah ada (privat, folder baru `reports`).
- **Filter divalidasi ulang di Job** dengan izin/role yang tercatat, agar ekspor tertunda tidak melewati scope pemohon.
- **Scope guru:**
  - presensi siswa dan nilai dibatasi pada rombel yang diajar/diwalikan;
  - pada nilai, kolom mapel hanya yang diajar, kecuali untuk rombel perwaliannya (semua mapel).
- **Ekspor nilai per mapel** di halaman nilai guru dan **ekspor keuangan** di halaman Rekap tetap ada. Pusat laporan menjadi pintu utama.

## Hasil

- Modul **Report**: `Report` (abstrak), `ReportContext` (user + role aktif + scope rombel), `ReportRegistry`, `ReportData`, `ReportRunner`, `ReportRenderer`.
  - 7 laporan: presensi siswa, presensi guru, nilai akhir, status raport, penerimaan keuangan, tunggakan, pendaftar PPDB.
  - Setiap laporan mendefinisikan izin (role + izin tambahan), filter (untuk UI), aturan validasi, dan cara menyusun data.
- Pusat laporan `/kepala-sekolah/laporan`, `/operator/laporan`, `/guru/laporan`:
  - daftar laporan, filter, pratinjau 50 baris pertama (dengan total baris & baris total);
  - tombol **Unduh PDF** / **Unduh Excel** (lewat `fetch`, file langsung terunduh atau pesan "sedang disiapkan"), riwayat ekspor 24 jam dengan status yang disegarkan otomatis.
- Menu "Laporan" operator diperbaiki (`/operator/laporan`) dan ditambahkan untuk guru.
- **PDF**: dompdf, kop sekolah + logo, judul, keterangan filter, tabel dengan angka rata kanan & rupiah berformat, baris total, "Dicetak … oleh …" dan nomor halaman, landscape untuk tabel lebar.
- **Excel**: judul, nama sekolah & filter di atas, header tebal, angka & rupiah tetap numerik (format `#,##0`).
- **Ekspor besar**:
  - di atas `skoolia.reports.direct_limit` (default 300 baris) dibuat catatan `report_exports` lalu diproses `GenerateReportExport` (izin & filter dicek ulang);
  - file privat di folder `reports`, notifikasi in-app + email berisi tautan `/laporan/ekspor/{id}`;
  - tautan hanya untuk pemilik (orang lain 404, `/files/...` 403), kedaluwarsa 24 jam (diarahkan dengan pesan), dibersihkan `model:prune` tiap jam.
- Scope guru:
  - presensi siswa & nilai hanya rombel yang diajar/diwalikan (rombel lain ditolak validasi);
  - kolom nilai hanya mapel yang diajar, kecuali di rombel perwalian.
- Ekspor tercatat di audit log (`report`). `robots`/slug website: `laporan` masuk slug terlarang.
- Tambahan:
  - `postForDownload()` & `filenameFromDisposition()` di `lib/http.ts` (dengan test Vitest);
  - konfigurasi `REPORT_DIRECT_LIMIT`.
- **Bug yang ditemukan & diperbaiki:**
  - helper test bernama sama (`reportScenario`) dengan file test lain membuat run paralel gagal fatal → diganti nama;
  - kolom `expires_at` bertipe `timestamp NOT NULL` ditolak MariaDB → `dateTime`.
- 12 test baru (`ReportCenterTest`) + 2 Vitest. 588 test Pest + 31 Vitest lulus; pint, phpstan, eslint, prettier, tsc, dan build hijau. Screenshot 1440/360 pusat laporan tanpa overflow halaman (tabel lebar bergulir di dalam kartu).
