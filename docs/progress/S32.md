# S32 — Audit keamanan

## Rencana

1. **Security headers** (middleware global):
   - CSP berbasis nonce: izinkan Pusher, Midtrans Snap, Google Fonts, dan peta Google di halaman Kontak;
   - `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy` (geolokasi hanya untuk situs sendiri, dipakai presensi guru);
   - HSTS hanya di produksi lewat HTTPS.
2. **Test suite Ownership** berbasis dataset: siswa, tagihan, kwitansi, raport, percakapan, kondisi anak, file, dan pendaftaran PPDB. Setiap baris menguji:
   - aktor sah dapat 2xx/3xx (memastikan URL benar);
   - role lain dan orang tua/guru/pendaftar lain dapat 403/404.
3. **Audit controller:**
   - pemindaian semua route ber-parameter model tanpa `authorize()`/pemeriksaan setara;
   - pemindaian query `Student` tanpa `visibleTo`;
   - test arsitektur: semua route portal wajib `auth` + `active.role`.
4. **Upload:**
   - MIME dari isi file sudah ada (S05); tambah test file PHP yang menyamar sebagai gambar;
   - `.htaccess` di folder upload publik (matikan eksekusi PHP) dan privat (tolak semua).
5. **Session:**
   - cookie `secure` otomatis di produksi, `http_only`, `same_site=lax`, lifetime 120 menit;
   - semua sesi lain dikeluarkan saat ganti password (mandiri & lewat email reset). Reset oleh operator, nonaktif, dan hapus user sudah melakukannya sejak S07.
6. Temuan & perbaikan dicatat di `docs/SECURITY_REVIEW.md`.

## Keputusan

- **`style-src` memakai `'unsafe-inline'`**, karena komponen UI (sonner, Radix, Recharts) menyisipkan style saat runtime. `script-src` tetap ketat dengan nonce (tanpa `unsafe-inline`/`unsafe-eval`). Risiko sisa kecil karena injeksi HTML sudah dicegah sanitasi & escaping.
- **CSP bisa dialihkan ke mode *report-only* lewat `.env`** (`CSP_REPORT_ONLY=true`) untuk berjaga-jaga saat go-live. Default ditegakkan.
- **Saat Vite dev server berjalan (lokal)**, origin HMR ditambahkan otomatis ke CSP.
- **Route monitoring kepala sekolah** (presensi per rombel) cukup dibatasi role, karena kepala sekolah berhak melihat semua rombel. Dicatat, bukan diubah.

## Hasil

Laporan lengkap: `docs/SECURITY_REVIEW.md` (10 temuan: 1 tinggi, 3 sedang, 3 rendah diperbaiki; 3 informasi dicatat).

- **Header keamanan** (`App\Http\Middleware\SecurityHeaders`, global):
  - CSP bernonce: script ketat; Midtrans, Pusher, Google Fonts, Google Maps diizinkan;
  - `X-Frame-Options`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`, HSTS produksi;
  - opsi `CSP_ENABLED`, `CSP_REPORT_ONLY`, `HSTS_ENABLED`;
  - diverifikasi di Chrome (aset build produksi): tidak ada pelanggaran CSP di website publik & 4 portal.
- **Cache website publik:** nonce diganti placeholder saat disimpan; hash manifest Vite ikut kunci (tidak ada HTML basi yang merujuk aset lama setelah rilis).
- **Sesi:**
  - ganti password sendiri → sesi dibuat ulang + sesi lain dihapus + token "ingat saya" diganti (audit log);
  - reset lewat email → semua sesi dihapus;
  - cookie `secure` default di produksi.
- **Ekspor Excel:** `SafeValueBinder` mencegah formula injection di semua ekspor.
- **Otorisasi sebelum validasi** di `PaymentRequest`, `SendMessageRequest`, `UpdateConversationRequest`.
- **`.htaccess`** di `storage/`, `storage/app/private`, `storage/app/public` (ikut Git).
- **Test suite keamanan** (`tests/Feature/Security`, 44 test):
  - `OwnershipTest` — dataset 27 route, aktor sah lolos, aktor lain 403/404;
  - `RouteProtectionTest` — middleware wajib, daftar route publik, throttle;
  - `HardeningTest`.
- **Audit tanpa temuan:**
  - pemindaian otorisasi 32 route kandidat;
  - query `Student` & `visibleTo`;
  - SQL mentah;
  - `composer audit` & `npm audit` (0 kerentanan).
- **Bug yang ditemukan saat verifikasi:**
  - host IPv6 Vite dev (`[::1]`) tidak valid di sintaks CSP → khusus lokal memakai sumber skema;
  - binder PhpSpreadsheet bersifat global → dikembalikan ke bawaan setelah render ekspor.
- 632 test Pest + 31 Vitest lulus; pint, phpstan, eslint, prettier, tsc, dan build hijau.
