# S02 — Arsitektur modular

## Rencana

1. `App\Providers\ModuleServiceProvider` (abstract): load `routes/web.php` (group `web`), `Database/Migrations`, `$policies`, `$listen`; nama & path modul diturunkan dari namespace provider.
2. `php artisan make:module {name}`: kerangka folder sesuai CLAUDE.md, stub provider + routes di `stubs/module/`, folder frontend `resources/js/Modules/<Name>/{Pages,Components}`, provider otomatis ditambahkan ke `bootstrap/providers.php`.
3. Resolver Inertia `Module::Path` di `resources/js/lib/resolve-page.ts` dengan fallback `./pages/**`.
4. Modul Core + halaman `Core::Welcome` di `/`.
5. `App\Support\ActivePeriod` (stub, singleton) dan trait `App\Support\Concerns\HasPublicId`.
6. Test Pest: struktur make:module, render Core::Welcome, HasPublicId.

## Keputusan

- Folder frontend `components/` → `Components/`, `layouts/` → `Layouts/` mengikuti §3.3; `hooks/`, `lib/`, `types/`, `pages/` tetap huruf kecil.
- Namespace modul didaftarkan ke `inertia.view-finder` & `inertia.testing.view-finder` sehingga `assertInertia()->component('Core::Welcome')` memverifikasi file halaman.
- `app.blade.php` memakai `App\Support\InertiaPage::sourcePath()` untuk `@vite` preload halaman (bawaan starter kit hanya mengenal `pages/`).
- Factory model modul di-resolve ke `App\Modules\<M>\Database\Factories\<Name>Factory` lewat `Factory::guessFactoryNamesUsing`.
- `Model::preventLazyLoading()` aktif di non-produksi (cegah N+1 sejak awal).

## Hasil

- `make:module Demo` + satu route + satu halaman langsung ter-render (200, chunk ter-preload), lalu modul Demo dihapus.
- 45 test lulus; pint, phpstan, eslint, tsc, build hijau.
