# S33 — Performa

## Rencana

1. Audit N+1 dengan data demo lengkap: setiap halaman utama & detail per role diukur jumlah query dan query berulang. `preventLazyLoading` sudah aktif di non-produksi sejak S01.
2. Index database untuk kolom filter/join yang sering dipakai. Periksa juga apakah query benar-benar bisa memakai index (EXPLAIN).
3. Cache: settings, ActivePeriod, profil sekolah, permission, dashboard (sudah ada), cek props bersama Inertia per request, dan pastikan `php artisan optimize` berjalan (config/route/view/event cache).
4. Frontend: ukur bundle; muat terpisah (lazy) komponen berat: editor TipTap dan grafik Recharts.
5. Gambar: kompresi sudah ada (≤ 1600 px). Tambah thumbnail untuk daftar, kartu, dan galeri.

## Keputusan

- **Tanpa tag cache**: invalidasi tetap berbasis versi/TTL (driver `file`/`database` di shared hosting).
- **Thumbnail** dibuat saat upload untuk JPG/PNG/WebP yang lebih besar dari 480 px:
  - disimpan di subfolder `thumbs/` dengan visibility sama;
  - disajikan lewat `?ukuran=kecil` (policy yang sama dengan file asli);
  - file lama dibuatkan dengan `php artisan skoolia:thumbnails` (sekali setelah rilis).
- **Detail & lightbox tetap memakai gambar asli**. Avatar, kartu, grid galeri, dan daftar memakai thumbnail.
- **Filter tanggal pada jalur ramai memakai rentang setengah terbuka** (`>= awal AND < akhir+1`), bukan `whereDate()`. `whereDate()` menjadi `DATE(kolom)` di MySQL sehingga index tidak terpakai.

## Hasil

- **N+1:**
  - test `QueryBudgetTest` men-seed data demo lengkap lalu membuka 52 halaman (4 portal + detail terberat + website publik);
  - query identik tidak boleh berulang > 6 kali, total ≤ 80 per halaman;
  - hasil: tidak ada pola N+1, maksimum 41 query (dashboard guru); test ini tetap menjadi pengaman regresi.
- **Index:**
  - index komposit utama sudah ada sejak sesi-sesi awal;
  - ditambah `attendance_sessions(date)` (rekap/tren lintas rombel), `notifications(notifiable, read_at)` (hitung belum dibaca tiap request), `website_pages`/`website_galleries(status, publish_at)`.
- **Filter tanggal:**
  - macro `whereDateBetween()` / `whereOnDate()` (`App\Support\QueryMacros`) dipakai di rekap presensi, dashboard, timeline, kalender kegiatan, laporan & rekap keuangan, pengingat tagihan, presensi guru;
  - EXPLAIN MySQL: bentuk lama `possible_keys=NULL`, bentuk baru memakai `attendance_sessions_date_index`.
- **Cache:**
  - props bersama Inertia sudah lazy dan data statis sudah di-cache;
  - tidak ada `env()` di luar `config/`;
  - `php artisan optimize` berhasil (config, events, routes, views), termasuk route `/{slug}` website yang didaftarkan setelah boot.
- **Frontend:**
  - grafik (Recharts) dan editor (TipTap) dimuat lazy dengan skeleton setinggi komponen aslinya;
  - chunk halaman dashboard kepala sekolah turun dari 392 kB → 10 kB (grafik menyusul);
  - form CMS tidak lagi memuat 406 kB editor sebelum tampil;
  - entry `app.js` (±173 kB gzip) berisi React, Inertia, dan axios — tidak ada kode modul yang ikut.
- **Thumbnail:**
  - dibuat otomatis (sisi terpanjang 480 px, kualitas 75) dan dihapus bersama file asli oleh `model:prune`;
  - dipakai di website publik (kartu berita, galeri, guru), panel CMS (daftar berita, banner, galeri), portofolio, kegiatan, kondisi anak, pengumuman, dan semua avatar;
  - 62 gambar demo dibuatkan thumbnail dengan `skoolia:thumbnails`.
- 7 test baru (`tests/Feature/Performance`).
- 638 test Pest + 31 Vitest lulus; pint, phpstan, eslint, prettier, tsc, dan build hijau.
